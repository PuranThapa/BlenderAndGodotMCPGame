# Asset Manifest

Units: 1 Godot unit = 1 m. Blender scenes use metric meters, scale 1.0, and +Y up after glTF export (assets face Blender +Y, which becomes Godot −Z forward).
Models, the newspaper art and all audio are generated by scripts in this repository. **Ground and hedge photo textures come from Pixabay** (Pixabay Content License: free for use in games, no attribution required). Sources are logged below and in `assets/textures/pixabay/CREDITS.json`. Most game audio uses **real recordings from Openverse** (CC0 or CC-BY; see below). The rest are synthesized by `assets/audio/source/gen_audio.py` (original work, CC0).

## Pipeline notes
- Regenerate an asset headlessly (about 4 s, independent of the open Blender UI):
  `/Applications/Blender.app/Contents/MacOS/Blender -b --factory-startup --python assets/blender/build_bicycle.py`
  The script exports the GLB, saves the `.blend` (only the asset scene), and renders a preview PNG.
- Then run `Godot --headless --path . --import`.
- `assets/blender/` contains a `.gdignore` so Godot doesn't try to import `.blend` files directly; that would need Blender configured in the editor.
- Coordinates are authored in Godot space through a `g()` helper, so node origins match the pivot constants in `bike_visual.gd`.
- Props: `Blender -b --factory-startup --python assets/blender/build_props.py` rebuilds every prop GLB, `props.blend`, and `assets/reference/props_preview.png`.
- Checking an exported GLB: `Blender -b --factory-startup --python assets/blender/preview_glb.py -- out.png a.glb b.glb` re-imports the actual GLB files and renders them close up. This is how the animal proportions were caught and fixed.
- Shared helpers live in `assets/blender/bkit.py`. `Builder.box()` sizes are in Blender axes; wrap Godot-order sizes in `gs(w, h, d)`.
- The city builder loads models through `_model()` and falls back to primitives if a GLB is missing, so the game always runs.
- Rider and pedestrian: `Blender -b --factory-startup --python assets/blender/build_rider.py [-- pedestrian]`
- House kit: `Blender -b --factory-startup --python assets/blender/build_houses.py`

## Pixabay photo textures (`assets/textures/pixabay/`)
Fetched with `assets/textures/source/pixabay_fetch.py`. The tool searches the Pixabay API and builds contact sheets for choosing; for the chosen image it downloads the 1280 px CDN version, flattens the lighting, makes it seamless with a half-offset cosine blend, and derives a normal map. Godot imports these with mipmaps and VRAM compression (set in the `.import` files). The API key is read from `~/.zshrc` and is never stored in the repo.

## Openverse sound recordings (`assets/audio/openverse/`)
Fetched with `assets/audio/source/openverse_fetch.py` from https://api.openverse.org (no key needed). Searches are limited to licenses that allow **commercial use and modification** (CC0 / CC-BY / CC-BY-SA). Each file is converted to mono 44.1 kHz, trimmed, peak-levelled, and looped where noted, and gets a waveform/spectrogram check image in `check/`. The game applies per-file loudness trims to match the levels it was tuned for (`REAL_TRIM_DB` in `scripts/systems/audio.gd`).
